# Be Organic: Elementor Pro templates

These are the Contact, Did You Know (blog) and Single Story pages built from the client mockups. They use a 1300px container, global colors and fonts, Grid containers, and Loop Grid for the dynamic stories.

## Files (`dist/`)

| File | Use |
|---|---|
| `be-organic-kit.zip` | **Main file.** Global colors (12), global fonts (12), 1300px width, Header, both Footers, Single Post, two Loop Item cards, and the Contact + Did You Know pages, all in one import |
| `be-organic-sample-stories.xml` | The 7 sample stories (Turmeric, Moringa, Beetroot …) with categories, featured images, excerpts and custom fields |
| `templates/*.json` | Every template as a separate JSON file, for when only one needs re-importing |
| `site-settings.json` | Reference copy of the global colors and fonts |

## Install steps (in this order)

1. **Kit import:** Elementor → Tools → Import/Export → *Import a Template Kit* → `be-organic-kit.zip` → select everything → Import.
   This sets the global colors, fonts and 1300px width, imports all templates, and creates the "Contact" and "Did You Know" pages. Images are downloaded into the Media Library automatically.
   Import the kit **only once**. A second import adds duplicate copies of the global colors.
2. **Stories:** Tools → Import → WordPress → `be-organic-sample-stories.xml` → tick "Download and import file attachments".
3. **Loop Grid template (1 click):** if the Loop Grid on the Did You Know page or in the Single Post template shows "Choose a template", select it from the dropdown:
   * Top grid (1 post) → **Be Organic - Loop Item - Spotlight**
   * Stories grid and Keep exploring → **Be Organic - Loop Item - Story Card**
4. **Contact footer:** Templates → Theme Builder → *Be Organic - Footer (Contact page)* → Display Conditions → Include → Singular → Page → **Contact**.
5. **Menu:** the header Nav Menu widget picks up the site's first menu automatically. To use a different one, select it from the dropdown.
6. If a "Contact" page already exists on the site, the kit creates the new one as `contact-2`. Delete or rename the old page, then set the new page's slug to `contact`.

## Editing globally

Site Settings → Global Colors / Global Fonts. Every page updates from here.

* Forest Green (Primary) `#1F3D2B`, Golden Harvest (Secondary) `#B38746`, Body Text `#4A4841`, Sage Mist (Accent) `#DCE3D3`, Cream Canvas `#F8F4EE`, and others.
* Headings: **Newsreader**; body text: **Jost**.

## What is dynamic

* **Did You Know:** the Spotlight shows the latest post. The grid shows the next 6 posts, and the Taxonomy Filter (All Stories / Ingredient Origins / Kitchen Tips) filters it without a page reload.
* **Single Post:** title, featured image, content, author, and a Table of Contents built from the H2 headings in the content. Related posts appear under "Keep exploring".
* Custom fields on each post: `bo_eyebrow` (gold label), `bo_subtitle` (line under the title), `bo_read_time` (e.g. "5 min read").
* Forms (Contact + newsletters) send to the admin email. Change this under Form → Actions After Submit.

## Development

The templates are generated by Python, so the JSON is always valid:

```bash
python3 src/build.py
```

`src/theme.py` holds the colors and fonts, `src/pages.py` holds the layouts.
